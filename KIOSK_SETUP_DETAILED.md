## 1. Установка приложения

1. Откройте браузер на планшете
2. Перейдите по ссылке: **https://go-market.kz/apk/tablet/**
3. Скачайте файл `app-release.apk`
4. Откройте скачанный файл и установите приложение
5. **НЕ запускайте приложение пока!**

---

## 2. Включение режима разработчика

1. Откройте **Настройки** на планшете
2. Перейдите в **О планшете** (или **О телефоне**)
3. Найдите пункт **Номер сборки** (или **Версия сборки**)
4. **Тапните по нему 7 раз подряд**
5. Появится сообщение "Вы стали разработчиком!"
6. Вернитесь в **Настройки**
7. Найдите новый раздел **Для разработчиков** (или **Параметры разработчика**)
8. Включите переключатель **Отладка по USB**
9. Найдите настройку **Не выключать экран** (или **Оставаться активным при подключении**) и включите её

---

## 3. Установка ADB на Windows

1. Скачайте **Platform Tools** с официального сайта:
   - Перейдите: https://developer.android.com/tools/releases/platform-tools
   - Скачайте архив для Windows
   - Или используйте прямую ссылку: https://dl.google.com/android/repository/platform-tools-latest-windows.zip

2. Распакуйте архив в удобное место (например: `C:\adb\`)

3. Добавьте ADB в переменные окружения:
   - Нажмите `Win + R`, введите `sysdm.cpl` и нажмите Enter
   - Перейдите на вкладку **Дополнительно**
   - Нажмите **Переменные среды**
   - В разделе **Системные переменные** найдите `Path` и нажмите **Изменить**
   - Нажмите **Создать** и добавьте путь к папке с ADB (например: `C:\adb`)
   - Нажмите **ОК** во всех окнах
   - **Перезапустите командную строку** (PowerShell или CMD)

4. Проверьте установку ADB:
   - Откройте новую командную строку (PowerShell или CMD)
   - Введите: `adb version`
   - Должна отобразиться версия ADB (например: `Android Debug Bridge version 1.0.41`)

## 4. Подключение планшета и команды ADB

### 4.1 Подключение

1. Подключите планшет к компьютеру через USB кабель
2. На планшете появится запрос **Разрешить отладку по USB?**
3. Поставьте галочку **Всегда разрешать с этого компьютера**
4. Нажмите **Разрешить**

### 4.2 Проверка подключения

```bash
& "$env:ANDROID_HOME\platform-tools\adb.exe" devices
```

**Ожидаемый результат:**
```
List of devices attached
XXXXXXXXXXXX    device
```

### 4.3 Установка Device Owner

```bash
& "$env:ANDROID_HOME\platform-tools\adb.exe" shell dpm set-device-owner com.gomarket/.KioskAdminReceiver
```

**Ожидаемый результат:**
```
Success: Device owner set to package com.gomarket
Active admin set to com.gomarket/.KioskAdminReceiver
```

### 4.4 Запуск приложения

```bash
& "$env:ANDROID_HOME\platform-tools\adb.exe" shell am start -n com.gomarket/.MainActivity
```

**Ожидаемый результат:**
```
Starting: Intent { cmp=com.gomarket/.MainActivity }
```

## 5. Настройка камеры на планшете

> **Рекомендация:** Настройте камеру ДО активации киоск-режима. После активации киоска выход в настройки камеры потребует знания PIN-кода.

> **Важно:** Не сообщайте код доступа к панели настройки камеры клиентам и посторонним лицам.

### 5.1 Добавление камеры в IMOU SDK

1. Откройте приложение Go Market на планшете
2. Перейдите на экран авторизации (долгое нажатие на логотип)
3. Выберите вкладку **Камеры**
4. Введите код доступа: **784512**
5. Дождитесь загрузки списка устройств
6. Нажмите кнопку **+** (Добавить устройство)
7. Введите данные камеры:
   - **Серийный номер (Serial Number)** камеры
   - **Секретный ключ (Secret Key)** камеры

 

8. На шаге подключения к Wi-Fi камеры — **НЕ нажимайте «Подключиться автоматически»**
9. Вместо этого вручную перейдите в **Настройки Wi-Fi** планшета и подключитесь к сети камеры (IMOU AP)
10. Вернитесь в приложение и нажмите **Я подключился** → **Продолжить**
11. Следуйте дальнейшим инструкциям на экране для завершения привязки

### 5.2 Привязка камеры к устройству

После добавления камеры в IMOU SDK, нужно привязать её к устройству для записи при заказе:

1. Вернитесь на экран авторизации
2. Выберите вкладку **Админ** и войдите по коду администратора
3. В админ-панели нажмите кнопку **Камера**
4. В модальном окне введите те же данные:
   - **Серийный номер (Serial Number)** камеры
   - **Секретный ключ (Secret Key)** камеры
5. Нажмите **Сохранить**

После этого камера будет автоматически включаться и записывать видео при каждом оплаченном заказе.

## 6. Настройка камеры на сайте

> **Примечание:** Настройка камеры на сайте возможна, но **не рекомендуется** для экономии трафика и потоков. Каждый активный просмотр на сайте использует отдельный поток камеры. Если камера уже настроена на планшете — этого достаточно.

Если всё же требуется настроить:

1. Перейдите в **Админ-панель** на сайте
2. Откройте вкладку **Девайсы**
3. Раскройте счёт нужного пользователя
4. В таблице устройств найдите колонку **Действия**
5. Нажмите на **зелёную иконку** (настройка камеры)
6. Введите:
   - **Серийный номер (Serial Number)** камеры
   - **Секретный ключ (Secret Key)** камеры
7. Сохраните

## 7. Активация киоск-режима

> **Рекомендация:** Перед активацией киоск-режима убедитесь, что камера уже настроена (раздел 5). После активации киоска для доступа к настройкам потребуется PIN-код.

Киоск-режим активируется автоматически после установки Device Owner (шаг 4.3) и запуска приложения.

После активации:
- Приложение Go Market работает в полноэкранном режиме
- Все системные кнопки заблокированы
- Статус-бар скрыт
- Выход из приложения только по PIN-коду администратора

## 8. Обновление приложения

```bash
powershell -Command "(New-Object Net.WebClient).DownloadFile('https://go-market.kz/apk/tablet/app-release.apk', 'app.apk'); & '$env:ANDROID_HOME\platform-tools\adb.exe' install -r app.apk"
```

**Ожидаемый результат:**
```
Performing Streamed Install
Success
```

---

## 9. Важные замечания

- **Device Owner можно установить только на чистом устройстве:**
  - Устройство должно быть сброшено до заводских настроек
  - НЕ добавляйте Google аккаунт или другие аккаунты
  - НЕ настраивайте устройство до установки Device Owner

- **Не выключайте экран планшета** во время установки Device Owner

- **После установки Device Owner** его нельзя удалить обычным способом — только через сброс устройства

- **Порядок настройки:** Установка APK -> ADB -> Device Owner -> Настройка камеры -> Киоск-режим

---

## 10. Решение проблем

### Ошибка "Not allowed to set the device owner"

**Причина:** На планшете уже есть аккаунты пользователей

**Решение:**
1. Выполните сброс устройства до заводских настроек
2. После сброса НЕ добавляйте Google аккаунт
3. Повторите все шаги с начала
