# 🔒 Тестирование киоск-режима AlashCloud

## 📱 Подготовка к тестированию

### 1. Сборка релизной версии
```bash
cd c:\Users\amang\Desktop\AlashCloudApp
npx react-native run-android --mode=release
```

### 2. Установка как Device Owner (ТОЛЬКО на сброшенном устройстве!)
```bash
# Проверяем что устройство сброшено и нет аккаунтов
adb shell dpm set-device-owner com.alashcloudapp/.KioskAdminReceiver
```

## 🚨 Тестирование ошибок

### Device Owner не установлен
**Симптомы:** 
- Киоск-режим не включается
- Все системные элементы доступны

**Решение:**
```bash
# Проверить статус Device Owner
adb shell dpm list-owners

# Если пусто - переустановить
adb shell dpm set-device-owner com.alashcloudapp/.KioskAdminReceiver
```

### Приложение не стартует после перезагрузки
**Проверить:**
- BootReceiver зарегистрирован в AndroidManifest.xml
- Разрешение RECEIVE_BOOT_COMPLETED добавлено

### Админ-панель не отключает киоск
**Проверить:**
- KioskModule корректно импортирован
- Логи в консоли React Native

## 🔧 Команды отладки

### Статус Device Owner
```bash
adb shell dpm list-owners
```

### Логи приложения
```bash
adb logcat | findstr AlashCloud
```

### Принудительное отключение Device Owner
```bash
adb shell dpm remove-active-admin com.alashcloudapp/.KioskAdminReceiver
```

### Сброс настроек (крайний случай)
```bash
adb shell am start -a android.settings.FACTORY_RESET
```
